# 🔬 Research & Publications

## Current Research Focus

As a Graduate Research Assistant at Oregon State University's College of Engineering, I focus on advancing software testing methodologies for High Performance Computing (HPC) systems, with particular emphasis on heterogeneous bug detection and fuzzing strategies.

## 📄 Publications

### "Automatically Detecting Heterogeneous Bugs in High-Performance Computing Scientific Software"
**Authors**: Davis, Matthew, **Aakash Kulkarni**, Manish Motwani  
**Publication**: arXiv preprint arXiv:2501.09872 (2025)  
**Status**: Submitted to ISC 2025, under review  
**Role**: First Author  

[📖 Download Paper](https://arxiv.org/pdf/2501.09872)

#### Abstract
With the growing demands of High Performance Computing (HPC) systems, there is an increasing requirement for identifying heterogeneous bugs in scientific software. Our research focuses on developing automated detection mechanisms for these complex bug patterns that emerge in distributed computing environments.

#### Key Contributions
- Novel fuzzing strategies specifically designed for HPC environments
- Automated detection algorithms for heterogeneous bug patterns
- Comprehensive benchmarking framework for scientific simulators
- Performance analysis of differential testing on divergent hardware

#### Research Impact
- Addresses critical gaps in HPC software reliability
- Provides practical tools for scientific computing communities
- Establishes new benchmarks for heterogeneous system testing
- Contributes to the broader field of software engineering research
